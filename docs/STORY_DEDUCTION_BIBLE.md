# 故事線與推理結構｜Little Chef 1.0 / v1.1 復刻

更新：2026-11-21

## 文件目的與證據界線

本文件把關卡流程整理成玩家能理解、能追蹤的推理線。它不是官方劇本逐字稿：公開來源主要記錄操作、任務與解鎖，沒有提供完整角色對白或完整世界觀。故分成：
- **來源支持的事件**：攻略、更新紀錄或開發者回覆明確支持的物件、順序、解鎖。
- **復刻版敘事串接**：為了讓玩家理解「為何要做下一步」而寫的旁白，不宣稱是原作台詞或官方設定。
- **待驗證**：有來源衝突、版本差異或缺少畫面，不能寫成確定事實。

## 故事主軸

玩家從 My Room 出發，依序整理三間廚房：Student Dorm、Cafe Job、Bistro。每間廚房都不是只靠做菜通關，而是要同時理解物件狀態、完成 To-Do、解開環境機關並探索 Good / Bad 食譜。三間主廚房都達到 100% 後，才會開啟 Rat Level。My Room 是樞紐與裝飾空間，不是第四間主廚房。

## 第一章｜Student Dorm：從生活痕跡開始

### 玩家看到的問題
宿舍廚房凌亂，餐具、羅勒、卡帶、櫃子與牆面磁磚都在提示：這裡的任務不只是料理。

### 推理鏈
1. **D2 磁磚 → 鑰匙 → Shane 的櫃子 → Cheese**：牆面磁磚不是裝飾，反覆調查後露出鑰匙；鑰匙打開 Shane 的櫃子。借來的 Cheese 必須進入一道 Good dish，才算完成借起司任務。
2. **Red Cassette + Green Cassette → Remix → 播放**：兩卷卡帶分別播放後，才能合成第三卷 Remix；完成播放才結束這條聲音線。
3. **清潔餐具 → 收好餐具 → Coffee Maker 出現 → 咖啡**：先整理水槽與餐具，才會露出咖啡設備；咖啡機需要被放到爐具並完成沖煮。
4. **水龍頭／濕海綿 → Basil**：讓海綿吸水後澆灌羅勒，或利用持續流出的水到達植物。
5. **料理探索**：完成 8 道以 Pasta 或 Ramen 為材料的料理，並累積 40 道新料理（Good + Bad）。

### 章末意義
完成宿舍 To-Do 與必要食譜探索後，Cafe Job 開放。這一章教會玩家：場景裡每件物品都可能是線索，食譜探索與環境解謎是兩套互相補充的系統。

## 第二章｜Cafe Job：交易、通訊與危機

### 推理鏈 A：老鼠與電話
1. 將 Cheese 交給藍茶壺旁的老鼠，取得撕下的紙條。
2. 把紙條放到電話附近，讀出號碼 **21931**。
3. 撥號後拿起聽筒並等待通話結束；完成後解鎖 Avocado 與 Lettuce。

這條線索由「老鼠交易」轉成「紙條訊息」，再轉成「電話操作」。不能只輸入號碼就跳過拿起聽筒與等待通話的步驟。

### 推理鏈 B：訂單與經濟
訂單紙會要求特定料理。完成指定料理後取得 Coin，取下完成的訂單並等待下一張。官方 v3.0ea 曾新增「完成 8 張訂單」To-Do；但不同版本的攻略與目前重建資料對目標數字有差異，最終 1.0 UI 任務總數仍需實機核對。不可把「8 orders」誤寫成「8 個獨立 To-Do」。

### 推理鏈 C：照片與保險箱
Photo 提供安全卡線索；Photo + Coin 得到 Security Card；Security Card 打開 Safe，發現 Void Bagel 相關隱藏食譜。後續三個 Bagel 的特殊處理與 Nothing Nowhere 成就需與一般料理配方分開記錄。

### 推理鏈 D：Panini 火災
Panini 加熱成 Burnt Panini，再次加熱引發火災；敲碎警報器玻璃三次，按下露出的警報按鈕，才解除警報。**引發火災**與**解除警報**是兩個不同事件，任務、成就與解鎖狀態不可混用。

### 章末意義
Cafe 的主線把物件線索、電話、訂單經濟與危機處理串在一起。完成 Level 2 To-Do 後才可進入 Bistro；目前來源只確認至少有訂單與火災等任務，完整任務列數仍待 1.0 實機 UI 核對。

## 第三章｜Bistro：兩條老鼠線與環境機關

### 推理鏈 A：抽油煙機後方的老鼠交易
1. 找到抽油煙機可疑位置／隱藏門。
2. 先交 Cheese，啟動交易；首次獎勵包含 Tomato（另有來源記載 Grape）。
3. 之後老鼠展示料理圖，玩家必須依圖製作指定料理，換取下一種食材。
4. 玩家攻略記錄的獎勵鏈涉及 Apple、Olives、Garlic 等特殊材料；完整請求順序、所有配方及最終 1.0 交易次數仍未全部核實。

**重要：** 交易線與七國磁鐵線是兩條不同進度。不能因為完成一次老鼠交易就直接增加國家磁鐵。

### 推理鏈 B：七國料理與磁鐵
完成七道國家料理後收集七枚磁鐵，對應 Going Global。可讀來源目前只有 Japan = Mochi 能以文字與圖片較可靠地對應；Apple Mochi 不等於日本磁鐵料理。其餘六道料理名稱與磁鐵對應必須保留待驗證，禁止自行補齊。

### 推理鏈 C：攪拌器、花盆與剪刀
- 花盆電路／保險絲是攪拌器電力線索；葉片下方藏有開關。
- 空 Mixer Jar 放入 Cooking Pot 的互動與剪刀取得有攻略支持；剪刀可用於懸掛繩索。
- Mixer 需要修復電源後啟動；研磨食材與連續運轉造成混亂是不同狀態。清潔混亂、剪斷繩索與完成食譜不能共用同一個完成旗標。

### 推理鏈 D：五瓶酒
檢查酒瓶標籤，依標籤高度由短到長排序五瓶酒。只放上五瓶不等於完成排序。

### 章末意義
Bistro 把玩家前兩章學到的狀態處理、配方判斷與物件觀察整合起來。三間主廚房都達到 100% 後，Rat Level 才會解鎖。

## 第四章｜Rat Level：反重力與雙火力

1. 調查畫像，找到反重力開關。
2. 啟動反重力，讓物件漂浮並露出花盆紙條。
3. 調查酒瓶標籤，揭露隱藏鍵盤。
4. 讀取紙條上的三位數密碼，再輸入鍵盤；密碼具體數字必須以目標版本可讀畫面或實機為準。
5. 解鎖 Electric Can Cooker。它最多接受兩項材料，且可切換低／高電力；相同材料在不同電力狀態可能得到不同結果。
6. 找齊 9 個 Good 與 12 個 Bad 配方槽位（候選數量，仍需遊戲內逐槽驗證）。

### 終章
Rat Level 的核心是把整個遊戲教過的技能倒過來考玩家：觀察畫面、找到被遮住的線索、串接物件狀態、辨認設備限制，再以實驗找出結果。完成秘密關卡後可記錄 Little Rat／Little Chef 等結局狀態；成就名稱與實際結局觸發條件需與 Steam 成就矩陣分開核對。

## My Room 與主線外支線

My Room 是 hub，另有裝飾、書本、便利貼、存檔與成就支線。20 Coin 解鎖畫筆的來源線索可用於裝飾流程。完成主線後出現生日蛋糕與媽媽的信，是 1.0 玩家通關記錄中的 post-game 線索；精確觸發條件尚未確認，不應在未滿足已知條件時提前播放。

## 實作硬性規則

- 事件旗標分離：`rat_trade_stage`、`country_magnets`、`fire_started`、`fire_alarm_cleared`、`phone_called`、`safe_opened`、`mixer_powered`、`wine_sorted`、`rope_cut`、`anti_gravity_on`、`note_read`、`keypad_unlocked`、`rat_recipe_slots` 不可互相代替。
- To-Do 完成、成就完成、食譜發現、謎題解鎖與房間 100% 必須分開計算。
- 未確認配方或密碼不可當成主線唯一解；候選內容需標記並可替換。
- 進入下一關的 gate 必須依目標版本的完整 100% 規則，不得只檢查任務 checkbox 數量。
- 故事日誌只揭露玩家已觸發的章節；旁白標明為復刻版整理，不偽裝成官方角色對白。
