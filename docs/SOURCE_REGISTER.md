# Research Source Register

Updated: 2026-11-16  
Purpose: audit trail for all external research used in the Little Chef recreation. Source priority is based on directness and version relevance, not search ranking.

## Evidence hierarchy

| Rank | Source type | Use |
|---|---|---|
| A | In-game 1.0/v1.1 observation, official developer announcement, official patch note, direct developer reply | Highest priority for exact mechanics and version changes |
| B | Multiple independent player reports / guides that agree | Strong candidate evidence; still verify in-game |
| C | One detailed walkthrough or guide | Useful candidate; mark unverified |
| D | Old guide, translation, conflicting report, inferred formula | Keep as hypothesis only |

## Source conflict policy

- In-game 1.0/v1.1 behavior outranks all written guides.
- Official patch notes outrank player guesses, but only for facts explicitly stated in the patch note.
- Developer replies outrank ordinary player guesses for the interaction they address.
- Multiple independent player reports can raise confidence, but never become “verified in-game” without direct observation.
- A later guide is not automatically more accurate; check game version and whether it copied earlier material.
- If a page is only available in search snippets, record that limitation.
- Keep all conflicting formulas in docs/RECIPE_CONFLICTS.md; never silently choose one.
