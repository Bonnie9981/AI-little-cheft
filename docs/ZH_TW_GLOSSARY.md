# zh-TW Localization Glossary

更新：2026-11-16  
目標：台灣繁體中文（zh-TW），不是把簡體中文逐字轉成繁體。  
狀態：UI與系統術語基準；完整312筆料理名稱候選譯名見 docs/ZH_TW_RECIPE_TRANSLATIONS.md，仍需最後母語校對與UI長度測試。

## 原則

1. 以台灣常用詞為優先：起司、馬鈴薯、可頌、吐司、披薩、果昔、調理機。
2. 不直接沿用簡體中文攻略中的「芝士、土豆、牛角包、耗子、咖啡馆」等詞。
3. 食材、加工狀態、料理成品使用不同詞，不因中文看起來相似就合併。
4. 英文 recipe ID 永遠保留；翻譯只作顯示名稱，避免來源核對時失去對應。
5. 菜名有文化專名時，優先採台灣餐飲／食譜常用譯名；罕見料理第一次出現可加括號說明。
6. Good / Bad 是遊戲內分類，不代表現實食物的品質評價。暫定譯為「美味料理」與「怪奇料理」，避免把 Bad 全部翻成「失敗料理」。
7. 未查明的專名標成「暫定」，不可在資料庫標為 final。

## Sources and terminology notes

- Official Steam Traditional Chinese store page explicitly says Traditional Chinese is unsupported; the game lists English, German, and Simplified Chinese. The project’s zh-TW is therefore a new localization, not an official translation: https://store.steampowered.com/app/3376500/?l=tchinese
- Simplified Chinese community guide provides chapter names and draft translations, but is not authoritative for Taiwan usage: https://steamcommunity.com/sharedfiles/filedetails/?id=3686619896
- Community correction notes suggest Mochi = 日式麻糬, Salami Rose = 臘腸玫瑰, Kombucha = 康普茶, Croque Monsieur = 火腿起司三明治, Pumpkin Fries = 炸南瓜條, Meatloaf = 烘肉餅, Italian Rice Balls = 義式炸飯糰, Schnitzel = 炸肉排: https://steamcommunity.com/app/3376500/discussions/0/568165880361397181/
- Taiwan recipe usage supports 佛卡夏 for Focaccia: https://www.tehmag.com.tw/baking.php?NO=1&cNO=31&sNO=189 and https://cookpad.com/tw/搜尋/佛卡夏
- Taiwan menu usage supports 法式熱三明治 for Croque Monsieur: https://capellahotels.com/assets/docs/taipei/Plume_All_Day_Dining.pdf
- Taiwan food writing uses 古拉什 / 匈牙利燉肉 / 匈牙利燉牛肉; prefer 古拉什（匈牙利燉肉） because the game input says Meat rather than specifically Beef: https://www.sanmin.com.tw/product/index/005557643
